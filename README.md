# Cookbook

일상에서 즐기는 다양한 요리의 재료와 조리법을 기록하고 정리하는 개인 요리책입니다.

각 레시피는 재료, 계량, 조리 과정 및 요리별 참고 사항을 일관된 형식으로 정리합니다. 실제 조리에 활용하기 쉽도록 명확하고 구체적인 설명을 지향합니다.

## Recipe Structure

각 레시피는 다음과 같은 구성을 기본으로 합니다.

- **재료** — 요리에 필요한 식재료와 분량
- **밑간** — 재료의 기본적인 간과 풍미를 위한 사전 조리
- **양념** — 소스 및 양념의 재료와 배합
- **조리 방법** — 재료 준비부터 완성까지의 단계별 과정
- **조리 포인트** — 맛과 식감에 영향을 주는 핵심 사항

요리의 특성에 따라 필요한 항목을 추가하거나 생략할 수 있습니다.

## Measurement

별도의 표시가 없는 한 다음 계량 기준을 사용합니다.

| 단위 | 용량 |
|---|---:|
| 1큰술 | 15ml |
| 1작은술 | 5ml |
| 1컵 | 200ml |

재료의 무게는 g, 액체의 부피는 ml를 기본 단위로 사용합니다.

## Writing Guidelines

- 재료명은 일반적으로 통용되는 표준 명칭을 사용합니다.
- 분량과 계량 단위를 명확하게 표기합니다.
- 조리 과정은 실제 작업 순서에 따라 작성합니다.
- 조리 온도, 시간, 불 세기 등 필요한 조건을 구체적으로 명시합니다.
- 모호하거나 주관적인 표현보다 재현 가능한 설명을 우선합니다.
- 대체 재료를 사용하는 경우 원재료와 대체 재료의 차이를 고려해 분량을 조정합니다.
- 선택 사항이나 취향에 따른 조정은 기본 레시피와 구분하여 표시합니다.

## Goal

누구나 레시피를 이해하고 동일한 결과를 재현할 수 있도록, 정확하고 실용적인 요리 기록을 만들어 나갑니다.
