# 치킨 카레

캐러멜라이징한 양파와 볶은 표고버섯, 토마토로 깊은 풍미를 만들고, 따로 구운 닭다리살을 더해 완성하는 진한 일본식 치킨 카레. 간장과 굴소스, 우스터소스로 감칠맛을 보강하고 고형 카레 루로 맛과 농도를 맞춘다.

## 재료

| 재료 | 분량 | 비고 |
|---|---:|---|
| 닭다리살 | 150~180g | 뼈와 껍질을 제거한 제품 |
| 양파 | 1/2개 (약 100g) | 얇게 채 썬다 |
| 말린 표고버섯 | 1개 | 미리 불린다 |
| 토마토 | 1/2개 (약 80g) | 잘게 썬다 |
| 다진 마늘 | 1큰술 |  |
| 다진 생강 | 1/2큰술 |  |
| 무염버터 | 8g | 양파 볶기 |
| 식용유 | 2작은술 | 닭고기와 채소 볶기 |
| 고형 카레 루 | 20g | 제품에 따라 마지막에 양 조절 |
| 치킨 스톡 | 120ml | 저염 제품 권장 |
| 표고 불린 물 | 30ml | 이물질을 걸러 사용 |
| 진간장 | 1/2큰술 |  |
| 굴소스 | 1/2작은술 |  |
| 우스터소스 | 1/2작은술 |  |
| 소금 | 약 0.5g | 닭고기 밑간 |
| 미원 | 약 0.6g | 닭고기 밑간 |
| 소금 | 약간 | 양파 볶기 |
| 후춧가루 | 약간 | 닭고기 밑간과 마무리 |

## 재료 대체 및 조절

- **토마토가 없을 때:** 토마토 1/2개 대신 케첩 1큰술을 사용한다. 토마토를 넣었을 때보다 단맛과 식초의 산미가 강하고 수분은 적으므로, 마늘과 생강을 볶은 뒤 케첩을 넣어 짧게 볶는다. 케첩을 추가로 많이 넣으면 단맛과 산미가 강해질 수 있다.
- **우스터소스가 없을 때:** 생략해도 된다. 돈가스 소스는 더 달고 걸쭉해 카레의 단맛과 농도를 바꾸므로 같은 양으로 대체하지 않는다.
- **치킨 스톡을 사용할 때:** 농축액이나 큐브는 제품 설명에 따라 물에 희석한다. 카레 루와 간장, 굴소스에도 염분이 있으므로 저염 제품을 사용하고 마지막에 간을 맞춘다.
- **카레 루의 양 조절:** 우선 20g을 넣고 농도와 간을 확인한다. 제품마다 염도와 농도가 다르므로 되직하게 만들고 싶을 때만 조금씩 추가한다. 농도가 지나치게 되면 물이나 치킨 스톡을 소량 넣어 조절한다.

## 조리 방법

### 1. 표고버섯 불리기

1. 말린 표고버섯을 물에 충분히 불린다.
2. 불린 표고는 물기를 짜고 얇게 썬다.
3. 불린 물은 가라앉은 이물질을 피해서 고운 체로 거른 뒤 30ml 남긴다.

### 2. 닭고기 손질 및 염지하기 (조리 전)

1. 닭다리살의 힘줄과 질긴 연골, 과도한 지방을 정리한다.
2. 표면에 남아 있는 수분을 키친타월로 꼼꼼히 제거한다.
3. 소금 약 0.5g과 미원 약 0.6g을 닭고기 전체에 골고루 뿌린다.
4. 닭다리살을 망이나 채반에 올려 냉장고에서 최소 1시간 염지한다. 가능하면 12~24시간 염지하는 것을 권장한다.
5. 표면을 말리기 위해 덮지 않고 냉장 보관한다. 다른 식품에 닿거나 육즙이 떨어지지 않도록 전용 받침을 사용하고 냉장고 아래쪽에 둔다.
6. 굽기 직전에 닭고기 표면의 수분을 다시 확인하고, 남아 있으면 키친타월로 제거한다. 4~5cm 크기로 자른다.

### 3. 닭고기 굽기

1. 팬을 충분히 달군 뒤 식용유를 두른다.
2. 닭고기를 겹치지 않게 펼쳐 강불에서 표면이 진한 황금빛 갈색이 되도록 굽는다. 한 번에 굽기 어렵다면 나누어 굽는다.
3. 반대쪽도 노릇하게 구운 뒤 접시에 덜어 둔다. 이 단계에서는 겉면의 갈색 풍미를 내는 데 집중하고, 속까지 완전히 익히는 것은 카레에서 마무리한다.

### 4. 양파 캐러멜라이징하기

1. 닭고기를 구운 팬에 남은 기름을 활용해 채 썬 양파를 강불에서 볶는다.
2. 양파가 부드러워지고 수분이 나오기 시작하면 약불로 줄인다.
3. 소금 한 꼬집과 버터를 넣고 천천히 볶는다.
4. 양파가 충분히 부드러워지고 진한 황금빛 갈색이 될 때까지 약 15~25분 볶는다. 바닥에 양파가 눌어붙으면 물을 아주 조금 넣어 긁어내고, 검게 타지 않도록 불을 조절한다.

### 5. 표고버섯과 향신 재료 볶기

1. 캐러멜라이징한 양파에 얇게 썬 표고버섯을 넣는다.
2. 중불에서 표고의 수분을 날리며 충분히 볶는다.
3. 다진 마늘과 생강을 넣고 약 30~40초 볶아 향을 낸다. 마늘이 갈색으로 타지 않도록 주의한다.

### 6. 토마토 볶기

1. 잘게 썬 토마토를 넣고 중불에서 으깨면서 볶는다.
2. 토마토의 수분이 줄고 양파와 표고에 어우러져 걸쭉해질 때까지 볶는다.

### 7. 육수와 닭고기 넣기

1. 치킨 스톡 120ml와 표고 불린 물 30ml를 넣는다.
2. 진간장, 굴소스, 우스터소스를 넣고 팬 바닥에 남은 갈색 성분을 긁어 육수에 섞는다.
3. 구워 둔 닭고기를 넣고 끓인다.
4. 불을 줄여 닭고기가 속까지 완전히 익을 때까지 은근히 끓인다. 닭고기 중심부가 74°C에 도달했는지 확인한다.

### 8. 카레 루 넣기

1. 닭고기가 완전히 익으면 불을 끈다.
2. 고형 카레 루 20g을 잘게 나누어 넣고 완전히 녹인다.
3. 다시 약불로 켜고 눌어붙지 않도록 저으면서 2~3분 끓인다.
4. 농도와 간을 확인한다. 너무 되직하면 물이나 치킨 스톡을 조금씩 추가하고, 간이 부족할 때만 소금을 더한다.

## 계량 기준

- 1큰술 = 15ml
- 1작은술 = 5ml

## 조리 포인트

- 닭고기는 힘줄과 질긴 연골, 과도한 지방을 정리하고 표면의 수분을 제거한 뒤 밑간한다.
- 닭고기는 소금과 미원으로 밑간해 최소 1시간, 가능하면 12~24시간 냉장 염지한다. 망이나 채반에 올려 표면을 말리면 구울 때 갈색으로 잘 익고 고소한 풍미가 생긴다.
- 생닭은 다른 식품과 접촉하거나 육즙이 떨어지지 않도록 별도 받침을 사용해 냉장고 아래쪽에 보관한다.
- 닭고기를 굽기 전에 표면의 수분을 다시 확인해 제거한다. 팬에 한꺼번에 많이 넣으면 수분이 빠져나와 굽기보다 삶아지기 쉬우므로 나누어 굽는다.
- 양파는 처음 강불에서 볶아 수분을 끌어낸 다음 약불로 줄여 버터와 함께 천천히 볶는다. 검게 태우기보다 진한 황금빛 갈색이 되도록 조절한다.
- 표고버섯은 양파를 볶은 뒤 넣어 수분을 날리며 볶는다. 불린 물도 육수에 활용해 버리지 않는다.
- 마늘과 생강은 타기 쉬우므로 표고를 볶은 뒤 넣고 짧게 볶는다.
- 토마토는 육수에 바로 넣기보다 먼저 볶아 수분을 줄이고 양파와 어우러지게 한다.
- 진간장, 굴소스, 우스터소스와 고형 카레 루는 모두 간과 풍미에 영향을 준다. 치킨 스톡은 저염 제품을 사용하고 소금은 마지막에 간을 본 뒤 추가한다.
- 카레 루를 넣은 뒤에는 바닥에 눌어붙기 쉬우므로 약불에서 저어가며 짧게 끓인다.
- 닭고기는 카레 루를 넣기 전에 완전히 익힌다. 루가 들어가면 소스가 걸쭉해져 닭고기 익힘 상태를 확인하기 어려워진다.
