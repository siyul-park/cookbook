# 휘낭시에

태운 버터의 고소한 풍미에 아몬드가루와 과일청의 향을 더한 휘낭시에. 원본 레시피를 참고해 소량으로 조정하고, 계량하기 쉬운 분량으로 정리했다.

## 재료

| 재료 | 분량 | 비고 |
|---|---:|---|
| 무염버터 | 115g | 태우기 전 무게 |
| 흰자 | 90g | 약 3개 분량이나 무게로 계량 |
| 설탕 | 80g |  |
| 꿀 | 5g |  |
| 과일청 | 10g | 잘게 썰린 과육은 고르게 섞는다 |
| 아몬드가루 | 40g |  |
| 중력분 | 35g |  |
| 소금 | 1/8작은술 | 고운 소금 기준 |

## 조리 방법

### 1. 태운 버터 만들기

1. 냄비에 무염버터 115g을 넣고 중약불에서 녹인다.
2. 버터가 끓으며 수분이 날아가고 우유 고형분이 바닥에 가라앉아 갈색으로 변할 때까지 가열한다.
3. 고소하고 견과류 같은 향이 나면 바로 불에서 내린다. 고형분이 검게 타지 않도록 주의한다.
4. 갈색 침전물을 포함해 버터를 모두 사용한다. 태우는 정도에 따라 완성 중량은 달라지므로 별도로 무게를 맞추지 않고 전량 사용한다.
5. 반죽에 넣기 전 뜨겁지 않도록 식힌다.

### 2. 반죽 만들기

1. 볼에 흰자를 넣고 거품을 내지 않도록 가볍게 풀어준다.
2. 설탕, 꿀, 과일청, 소금을 넣고 설탕이 어느 정도 녹을 때까지 섞는다.
3. 아몬드가루와 중력분을 체 쳐 넣고 가루가 보이지 않을 때까지 섞는다.
4. 식힌 태운 버터를 2~3회 나누어 넣으며 반죽에 고르게 섞는다.

### 3. 반죽 휴지하기

1. 반죽 표면에 밀착해 랩을 씌우거나 밀폐 용기에 담는다.
2. 냉장고에서 최소 1시간 휴지한다.

### 4. 굽기

1. 오븐을 190°C로 예열한다.
2. 휘낭시에 틀에 버터를 얇게 바른다. 코팅된 틀은 제품 특성에 맞게 준비한다.
3. 반죽을 틀의 약 80~90%까지 채운다.
4. 190°C에서 약 13~16분 굽는다. 오븐과 틀 크기에 따라 굽는 시간은 조절한다.
5. 가장자리가 진한 황금빛 갈색이 되고 가운데까지 익으면 꺼낸다.
6. 틀에서 꺼내 식힘망 위에서 식힌다.

## 계량 기준

- 1작은술 = 5ml

## 조리 포인트

- 버터는 태우기 전 115g을 계량한다. 태우면 수분이 증발해 무게가 줄어드므로 태운 뒤 중량을 115g으로 맞추지 않는다.
- 버터 바닥에 생긴 갈색 유고형분에도 고소한 풍미가 있으므로 버리지 말고 반죽에 함께 넣는다. 검게 타면 쓴맛이 나므로 갈색이 되었을 때 가열을 멈춘다.
- 흰자는 거품을 많이 내지 않고 풀어 사용한다. 거품이 과하면 반죽에 불필요한 공기가 들어갈 수 있다.
- 태운 버터는 뜨거운 상태로 넣지 않는다. 반죽에 넣을 때는 뜨겁지 않도록 식혀 둔다.
- 반죽을 냉장 휴지하면 가루가 수분을 흡수하고 반죽이 안정된다.
- 과일청은 제품마다 당도와 수분량, 과육 크기가 다르다. 과육이 크면 잘게 다져 반죽에 고르게 섞는다.
- 굽는 시간은 오븐과 틀의 재질 및 크기에 따라 달라진다. 가장자리의 색과 가운데의 익힘 상태를 함께 확인한다.
