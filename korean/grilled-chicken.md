# 구운 치킨

파기름으로 닭고기의 풍미를 살리고, 노릇하게 구운 닭다리살에 매콤달콤한 양념을 더해 볶아낸 치킨. 진한 감칠맛과 고소한 풍미가 어우러져 밥과 함께 먹기 좋다.

## 재료

- 뼈 없는 닭다리살 500g
- 대파 1대
- 식용유 2큰술
- 떡볶이 떡 100g (선택)

## 밑간

| 재료 | 분량 |
|---|---:|
| 소금 | 1/2작은술 |
| 미원 | 1/2작은술 |

## 양념

| 재료 | 분량 |
|---|---:|
| 고춧가루 | 4큰술 |
| 설탕 | 4큰술 |
| 진간장 | 2큰술 |
| 다진 마늘 | 2.5큰술 |
| 미림 | 2큰술 |
| 청주 | 1큰술 |
| 쇠고기맛 조미료(다시다) | 1작은술 |
| 미원 | 1작은술 |
| 후춧가루 | 1/2작은술 |
| 굴소스 | 2작은술 |
| 케첩 | 1큰술 |
| 물 | 2큰술 |
| 청양고추 | 1개 (선택) |

## 재료 대체 및 조절

- **고추장 대신 고춧가루 사용:** 고추장 1큰술을 생략하고 고춧가루 2큰술을 추가한다. 따라서 고춧가루는 총 4큰술을 사용한다. 고추장의 구수하고 묵직한 발효 풍미와 농도는 줄어들고, 고춧가루 특유의 깔끔하고 선명한 매운맛이 살아난다. 양념은 고추장을 넣었을 때보다 덜 걸쭉해진다.
- **마늘 일부를 생강으로 대체:** 다진 마늘 2.5큰술 중 1/2큰술을 다진 생강 1/2큰술로 대체할 수 있다. 이때 다진 마늘 2큰술과 다진 생강 1/2큰술을 사용한다. 마늘의 진하고 알싸한 풍미는 조금 줄어들고 생강의 산뜻하고 알싸한 향이 더해져 맛이 한결 가벼워진다.
- **선택 감미 재료:** 기본 양념에는 별도의 시럽이나 과일청을 넣지 않는다. 과일 향을 더하고 싶으면 감귤류 과일청 1/2큰술, 과일 향 없이 단맛과 윤기를 더하고 싶으면 물엿 1/2큰술, 꿀 특유의 향을 더하고 싶으면 꿀 1/2큰술을 선택해 추가한다. 셋 중 하나만 사용하며, 선택하지 않아도 된다. 과일청은 감귤류의 향과 산미를 더하고, 물엿은 향을 크게 바꾸지 않으면서 윤기와 점도를 높이며, 꿀은 꽃향과 꿀 특유의 풍미를 더한다. 시럽을 추가하면 단맛이 강해지고 양념이 더 빨리 눌어붙을 수 있다.
- **케첩 대체(산미 없이):** 케첩 1큰술 대신 물엿 1작은술, 올리고당 1작은술 또는 꿀 1작은술 중 하나를 사용할 수 있다. 단맛과 윤기는 더해지지만 토마토 풍미와 산미, 케첩이 주는 양념의 부피감은 줄어든다. 물엿과 올리고당은 맛이 비교적 담백하고 윤기를 더하며, 꿀은 특유의 향이 더해진다. 단맛을 추가하지 않으려면 케첩을 생략하고 별도 재료를 넣지 않아도 된다.
- **매운맛 조절:** 청양고추는 기본 1개를 선택적으로 사용한다. 더 매콤하게 먹고 싶으면 1개를 추가해 총 2개를 사용하고, 매운맛을 줄이고 싶으면 생략하거나 씨를 제거한다. 청양고추를 추가하면 고춧가루의 매운맛과는 다른 신선하고 날카로운 매운 향이 더해진다.

## 마무리

| 재료 | 분량 |
|---|---:|
| 참기름 | 1작은술 |

## 조리 방법

### 1. 재료 준비하기

1. 떡볶이 떡은 찬물에 담가 부드러워질 때까지 불린 후 체에 밭쳐 물기를 뺀다.
2. 대파는 적당한 크기로 썬다.
3. 청양고추를 사용할 경우 잘게 썰어 준비한다.

### 2. 닭고기 밑간하기

1. 닭다리살의 표면에 남아 있는 수분을 키친타월로 제거한다.
2. 소금과 미원을 골고루 뿌려 닭고기에 밑간한다.
3. 냉장고에서 20~30분간 재워둔다.

### 3. 양념장 만들기

1. 청양고추를 제외한 양념 재료를 한데 넣고 골고루 섞는다.
2. 선택 감미 재료를 사용할 경우 이 단계에서 하나를 골라 넣는다.
3. 설탕이 녹도록 충분히 저어 양념장을 완성한다.

### 4. 파기름 내기

1. 팬에 식용유를 두르고 대파를 넣는다.
2. 중약불에서 천천히 볶아 대파의 향이 기름에 충분히 배도록 한다.
3. 대파가 진한 황금빛을 띠고 타기 직전에 건져낸다.

### 5. 닭고기 굽기

1. 대파를 건져낸 팬에 남은 파기름을 그대로 사용한다.
2. 닭다리살을 껍질이 아래로 향하도록 팬에 올린다.
3. 중불에서 껍질이 노릇하고 바삭해질 때까지 충분히 굽는다.
4. 뒤집어서 반대쪽도 노릇하게 익힌다.
5. 닭고기를 팬에서 꺼내 먹기 좋은 크기로 자른다.

### 6. 양념 넣고 볶기

1. 팬에 남은 기름이 많으면 적당량만 남기고 덜어낸다.
2. 준비한 양념장을 넣고 약불에서 가볍게 볶는다.
3. 구워둔 닭고기와 대파를 다시 넣는다.
4. 불린 떡볶이 떡과 준비한 청양고추를 넣는다. 청양고추를 생략하는 경우에는 넣지 않는다.
5. 양념이 닭고기와 떡에 골고루 배도록 볶는다.
6. 닭고기 속까지 완전히 익히고 양념이 적당히 졸아들면 불을 끈다.
7. 참기름을 넣고 골고루 버무려 마무리한다.

## 계량 기준

- 1큰술 = 15ml
- 1작은술 = 5ml

## 조리 포인트

- 떡볶이 떡은 미리 물에 불려 부드럽게 준비한다.
- 대파는 타지 않도록 중약불에서 천천히 볶아 향을 충분히 우려낸다.
- 닭고기는 껍질 부분을 먼저 충분히 구워 바삭한 식감과 고소한 풍미를 살린다.
- 설탕과 선택 감미 재료가 들어간 양념은 쉽게 탈 수 있으므로 양념을 넣은 후에는 약불을 유지한다.
- 참기름은 향을 살릴 수 있도록 불을 끈 후 넣는다.
- 양념을 지나치게 졸이지 않고 밥에 비벼 먹을 수 있도록 적당한 양의 소스를 남긴다.
- 닭고기는 중심부까지 완전히 익혀 조리한다.
