# 구운 치킨

파기름으로 닭고기의 풍미를 살리고, 노릇하게 구운 닭다리살에 매콤달콤한 양념을 더해 볶아낸 치킨. 진한 감칠맛과 고소한 풍미가 어우러져 밥과 함께 먹기 좋다.

## 재료

- 뼈 없는 닭다리살 500g
- 대파 1대
- 식용유 2큰술
- 떡볶이 떡 100g (선택)

## 밑간

| 재료 | 분량 |
|---|---:|
| 소금 | 1/4작은술 |
| 미원 | 1/2작은술 |

## 양념

| 재료 | 분량 |
|---|---:|
| 고춧가루 | 2큰술 |
| 고추장 | 1큰술 |
| 물엿 | 2큰술 |
| 감귤류 과일청 | 1/2큰술 |
| 설탕 | 4큰술 |
| 진간장 | 1.5큰술 |
| 다진 마늘 | 2큰술 |
| 다진 생강 | 1/2큰술 |
| 미림 | 2큰술 |
| 청주 | 1큰술 |
| 쇠고기맛 조미료(다시다) | 1작은술 |
| 미원 | 1작은술 |
| 후춧가루 | 1/2작은술 |
| 굴소스 | 2작은술 |
| 케첩 | 1큰술 |
| 물 | 2큰술 |
| 청양고추 | 1개 (선택) |

## 재료 대체 및 조절

- **고추장을 생략하고 싶을 때:** 기본 배합의 고추장 1큰술을 빼고 고춧가루를 2큰술 추가한다. 고춧가루는 총 4큰술을 사용한다. 고추장의 구수하고 묵직한 발효 풍미와 감칠맛, 양념의 걸쭉함은 줄어들고 고춧가루의 깔끔하고 선명한 매운맛이 강해진다.
- **고추장 일부를 두반장으로 대체:** 기본 배합의 고추장 1큰술 중 절반을 두반장 1/2큰술로 바꾼다. 고춧가루 2큰술, 고추장 1/2큰술, 두반장 1/2큰술을 사용한다. 두반장의 짭짤한 발효 콩 풍미와 감칠맛이 더해져 맛이 더 진하고 구수해지지만 짠맛도 강해진다. 두반장을 사용할 때는 진간장을 1큰술부터 넣고 볶은 뒤 간을 보며 조절한다.
- **생강이 없을 때:** 기본 배합의 다진 생강 1/2큰술을 생략하고 다진 마늘을 2큰술에서 2.5큰술로 늘린다. 생강 특유의 산뜻하고 알싸한 향은 줄어들고 마늘의 진하고 묵직한 풍미가 더 강해진다.
- **물엿 대체 및 과일청 활용:** 기본 배합의 물엿 2큰술은 단맛과 윤기를 더한다. 꿀로 바꿀 경우 물엿 2큰술 대신 꿀 1과 1/2큰술을 사용한다. 꿀은 꽃향과 부드러운 단맛을 더하지만 물엿보다 향이 강하고 윤기는 덜하다. 감귤류 과일청을 활용하고 싶으면 물엿 중 1/2큰술을 감귤류 과일청 1/2큰술로 바꾼다. 감귤류의 향과 산미가 더해지는 대신 소스의 점도와 윤기는 조금 줄어든다.
- **케첩을 사용하지 않을 때:** 케첩 1큰술 대신 물엿 1작은술, 올리고당 1작은술 또는 꿀 1작은술 중 하나를 사용할 수 있다. 단맛과 윤기는 더해지지만 토마토 풍미와 산미, 케첩이 주는 양념의 부피감은 줄어든다. 물엿과 올리고당은 맛이 비교적 담백하고 윤기를 더하며, 꿀은 특유의 향이 더해진다. 단맛을 추가하지 않으려면 케첩을 생략하고 별도 재료를 넣지 않아도 된다.
- **매운맛 조절:** 기본 배합에는 청양고추 1개를 선택적으로 사용한다. 더 매콤하게 먹고 싶으면 1개를 추가해 총 2개를 사용하고, 매운맛을 줄이고 싶으면 생략하거나 씨를 제거한다. 청양고추를 추가하면 고춧가루의 매운맛과는 다른 신선하고 날카로운 매운 향이 더해진다.

## 치밥용 선택 재료

| 재료 | 분량 |
|---|---:|
| 참기름 | 1작은술 |
| 깨소금 | 1작은술 |
| 김가루 | 적당량 |

※ 치킨과 밥을 비벼 먹을 때 기호에 따라 추가한다. 참기름은 고소한 향을, 깨소금과 김가루는 고소함과 감칠맛을 더한다.

## 조리 방법

### 1. 양념장 만들기 (하루 전)

1. 청양고추와 물을 제외한 양념 재료를 한데 넣고 골고루 섞는다.
3. 설탕이 녹도록 충분히 저어 양념장을 완성한다.
4. 밀폐 용기에 담아 냉장고에서 하루 이상 숙성한다. 미리 만들어 숙성하면 재료의 맛과 향이 양념에 고르게 어우러진다.

### 2. 재료 준비하기 (조리 당일)

1. 떡볶이 떡은 찬물에 담가 부드러워질 때까지 불린 후 체에 밭쳐 물기를 뺀다.
2. 대파는 적당한 크기로 썬다.
3. 청양고추를 사용할 경우 잘게 썰어 준비한다.

### 3. 닭고기 염지하기

1. 닭다리살의 표면에 남아 있는 수분을 키친타월로 제거한다.
2. 소금과 미원을 골고루 뿌려 닭고기 전체에 고르게 묻힌다.
3. 껍질이 위로 향하도록 망이나 채반에 올려 냉장고에서 최소 1시간 염지한다. 가능하면 12~24시간 염지하는 것을 권장한다.
4. 껍질 표면을 더 잘 말리려면 덮지 않은 상태로 냉장 보관하되, 다른 식품에 닿거나 육즙이 떨어지지 않도록 아래에 받침을 둔다.

### 4. 파기름 내고 불향 더하기

1. 팬에 식용유를 두르고 충분히 달군다.
2. 대파를 넣고 중강불에서 표면에 갈색 그을음이 부분적으로 생길 때까지 굽듯이 볶는다.
3. 대파가 검게 타서 쓴맛이 나지 않도록 살짝 그을린 상태에서 건져낸다.

### 5. 닭고기 굽기

1. 대파를 건져낸 팬에 남은 파기름을 그대로 사용한다.
2. 닭다리살을 껍질이 아래로 향하도록 팬에 올린다.
3. 중불에서 껍질이 노릇하고 바삭해질 때까지 충분히 굽는다.
4. 뒤집어서 반대쪽도 노릇하게 익힌다.
5. 닭고기를 팬에서 꺼내 먹기 좋은 크기로 자른다.

### 6. 양념 넣고 볶기

1. 팬에 남은 기름이 많으면 적당량만 남기고 덜어낸다.
2. 양념장을 넣고 중약불에서 저어가며 먼저 볶는다.
3. 양념의 색이 조금 짙어지고 가장자리가 살짝 눌어붙기 시작하면 물 2큰술을 팬 가장자리에 둘러 넣는다. 양념이 검게 타거나 쓴맛이 나지 않도록 주의한다.
4. 나무주걱으로 팬 바닥에 눌어붙은 양념과 갈색 고기 성분을 긁어 물에 녹인 뒤 소스에 섞는다.
5. 약불에서 양념을 가볍게 끓인 뒤 구워둔 닭고기와 대파를 다시 넣는다.
6. 불린 떡볶이 떡과 준비한 청양고추를 넣는다. 청양고추를 생략하는 경우에는 넣지 않는다.
7. 양념이 닭고기와 떡에 골고루 배도록 볶는다.
8. 닭고기 속까지 완전히 익히고 양념이 적당히 졸아들면 불을 끈다.

## 계량 기준

- 1큰술 = 15ml
- 1작은술 = 5ml

## 조리 포인트

- 떡볶이 떡은 미리 물에 불려 부드럽게 준비한다.
- 대파는 중강불에서 표면을 살짝 그을려 구운 향을 더한다. 검게 타면 쓴맛이 나므로 부분적으로 갈색 그을음이 생기는 정도로 볶는다.
- 닭고기는 최소 1시간, 가능하면 12~24시간 냉장 염지한다. 염지 후 껍질 표면의 수분을 잘 말리면 더 노릇하게 구울 수 있다.
- 닭고기는 껍질 부분을 먼저 충분히 구워 바삭한 식감과 고소한 풍미를 살린다.
- 양념을 먼저 볶아 색과 향을 낸 뒤 물을 넣고 팬 바닥에 눌어붙은 양념과 갈색 고기 성분을 긁어 소스에 섞는다. 검게 태우지 않도록 주의한다.
- 설탕과 과일청이 들어간 양념은 쉽게 탈 수 있으므로 양념을 넣은 후에는 불 조절에 주의한다.
- 참기름은 치킨에 미리 넣지 않고, 밥과 비벼 먹기 직전에 기호에 따라 넣는다.
- 양념을 지나치게 졸이지 않고 밥에 비벼 먹을 수 있도록 적당한 양의 소스를 남긴다.
- 닭고기는 중심부까지 완전히 익혀 조리한다.
